# Unused Material

This folder keeps files that are not part of the current active COBOL RAG pipeline.

Nothing here was deleted. These files were moved out of the active path so the repo is easier to work in.

## Contents

```text
input_samples/                  old/sample inputs not used by the current PDCBVC run
legacy_artifacts/combined/      old manual combined-output snapshot
generated_artifacts/            old generated outputs, experiments, reports, pycache
reference_docs/                 old notes, images, docx/txt references
anonymization/                  PII/anonymizer scripts, docs, reports, and related repo
external_repos/                 local cloned repos that are not active project code
legacy_final_scripts_root_files/ old helper files formerly beside active builders
```
